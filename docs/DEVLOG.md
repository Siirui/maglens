## 怎么用

```bash
# 翻译（不需要 API key，走 Claude 订阅，从最新一期往前）
python -m maglens.cli_runner --series popeye --model haiku
# 本机阅读（只读）
python run.py --manual
# 部署：第一次
deploy/setup.sh ubuntu@服务器IP 域名
# 部署：以后每次新翻了杂志或改了代码
deploy/sync.sh ubuntu@服务器IP
# 加朋友的账号（在服务器上）
python -m maglens.users --data-dir /opt/maglens/data add 名字
```
完整部署步骤见 [DEPLOY.md](DEPLOY.md)。

## 关键决定和原因

- **翻译走 `claude -p`，不用 API key。** 用户只有 Claude 订阅（含 usage credits），没有 Console API key。订阅的 OAuth token 不能给第三方程序当 API key 用，所以通过 Claude Code 的非交互模式逐页调用。Haiku 每页约 $0.01（按标价折算），一本约 1 小时。
- **只用于自己和少数朋友私下阅读。** 曾讨论过在小红书或闲鱼上售卖，但售卖杂志扫描件和译文属于侵权，所以这个方向放弃了。部署的设计都围绕"私下阅读"：不开放注册、禁止搜索引擎收录、页面图也要登录才能看。
- **服务器只读、不放 PDF。** 翻译只在本机进行。服务器上只有预渲染的 WebP 和一份精简数据库，不含本地路径和花费，也不调用任何模型。
- **服务器放在香港，不做备案。** 读者在大陆，香港延迟低；服务器不调模型，所以不受 Anthropic API 地区限制。机房选型以大陆晚高峰的实测为准。
- **字体本地托管。** Google Fonts 在大陆打不开，Dela Gothic One 抽成 13KB 子集放在 `web/fonts/`（SIL OFL 授权）。
- **项目和杂志都搬出了 Downloads**，因为担心 Downloads 被系统自动整理。杂志没放 `~/Documents`，因为那里开了 iCloud 同步。杂志按文件内容（大小 + 首尾各 1MB）识别，搬位置、改名都不影响已翻好的译文。

## 这次做了什么（按时间）

1. **跑通本地流程**：修好测试在 macOS 上缺字体的问题；手工翻译 11 月号的样张；实时人工模式（`--manual`），翻好一页网页就自动刷新。
2. **整套批量翻译**：写了 `cli_runner`。12 本从最新往前一本一本翻，每本完成时通知；碰到额度上限会自动暂停；超时按实际钟表时间计算，电脑睡眠后卡住的请求会被结束并重试；有防睡眠。
3. **阅读体验**：
   - 顶部进度条、杂志切换菜单；
   - 四种显示方式（整页、适应宽度、适应高度、铺满）和缩放（⌘/Ctrl+滚轮、双指捏合）；
   - 手机布局和左右滑动翻页；
   - 预加载后面两页。
4. **读者和管理员**：
   - 账号（scrypt 哈希加签名 cookie），登录防暴力破解；
   - 读者看不到管理按钮和花费，也不会触发任何模型调用（服务端强制）；
   - 没建账号时，经过反向代理来的请求一律拒绝。
5. **清理数据噪音**：
   - 自动识别下载站插入的推广页（13 页），阅读时跳过，跨页配对也随之修正；
   - 读者只看到有用的译注；
   - 隐藏只有编号的块和页面类型标签；
   - 每本自动找到真正的封面。
6. **部署**：`publish` 导出、`setup.sh` 一条命令初始化服务器、`sync.sh` 增量同步；修好了 macOS rsync 参数、远端文件权限、反向代理识别这几个问题。
7. **新视觉**：图标 A（红底、斜放的纸页、蓝色镜片）+ Dela Gothic 字标「MagLens」配片假名贴纸「マグレンズ」；首页改成街头风格：「继续阅读」黄卡片、按系列分区、封面加黑框和硬投影。

## 已知问题

- 4 月号第 145 页没有译文（内容过滤）。可以换 Sonnet 单独重试，也可以不管。
- Haiku 的小毛病：个别术语音译（如 Nomex 写成「诺梅克斯」），页面类型标签常标错（已对读者隐藏）。之前的译注噪音已经在显示层过滤，提示词也改了，但已经翻好的数据没有重翻。
- 「继续阅读」只记在当前浏览器里，换设备不同步。
- `deploy/setup.sh` 没有在真服务器上跑过，第一次运行时要留意报错。
