## 怎么用

```bash
# 翻译（不需要 API key，走 Claude 订阅，从最新一期往前）
python -m maglens.cli_runner --series popeye --model haiku
# 本机阅读（只读）
python run.py --manual
# 部署：第一次
deploy/setup.sh ubuntu@服务器IP 域名
# 部署：以后每次新翻了杂志或改了代码
deploy/sync.sh ubuntu@服务器IP
# 加朋友的账号：管理员登录网站后点右上角「账号」
```
完整部署步骤见 [DEPLOY.md](DEPLOY.md)。

## 关键决定和原因

- **翻译走 `claude -p`，不用 API key。** 用户只有 Claude 订阅（含 usage credits），没有 Console API key。订阅的 OAuth token 不能给第三方程序当 API key 用，所以通过 Claude Code 的非交互模式逐页调用。Haiku 每页约 $0.01（按标价折算），一本约 1 小时。
- **只用于自己和少数朋友私下阅读。** 曾讨论过在小红书或闲鱼上售卖，但售卖杂志扫描件和译文属于侵权，所以这个方向放弃了。部署的设计都围绕"私下阅读"：不开放注册、禁止搜索引擎收录、页面图也要登录才能看。
- **服务器只读、不放 PDF。** 翻译只在本机进行。服务器上只有预渲染的 WebP 和一份精简数据库，不含本地路径和花费，也不调用任何模型。
- **服务器放在香港，不做备案。** 读者在大陆，香港延迟低；服务器不调模型，所以不受 Anthropic API 地区限制。机房选型以大陆晚高峰的实测为准。
- **字体本地托管。** Google Fonts 在大陆打不开，Dela Gothic One 抽成 13KB 子集放在 `web/fonts/`（SIL OFL 授权）。
- **项目和杂志都搬出了 Downloads**，因为担心 Downloads 被系统自动整理。杂志没放 `~/Documents`，因为那里开了 iCloud 同步。杂志按文件内容（大小 + 首尾各 1MB）识别，搬位置、改名都不影响已翻好的译文。

## 这次做了什么（按时间）

1. **跑通本地流程**：修好测试在 macOS 上缺字体的问题；手工翻译 11 月号的样张；实时人工模式（`--manual`），翻好一页网页就自动刷新。
2. **整套批量翻译**：写了 `cli_runner`。12 本从最新往前一本一本翻，每本完成时通知；碰到额度上限会自动暂停；超时按实际钟表时间计算，电脑睡眠后卡住的请求会被结束并重试；有防睡眠。
3. **阅读体验**：
   - 顶部进度条、杂志切换菜单；
   - 四种显示方式（整页、适应宽度、适应高度、铺满）和缩放（⌘/Ctrl+滚轮、双指捏合）；
   - 手机布局和左右滑动翻页；
   - 预加载后面两页。
4. **读者和管理员**：
   - 账号（scrypt 哈希加签名 cookie），登录防暴力破解；
   - 读者看不到管理按钮和花费，也不会触发任何模型调用（服务端强制）；
   - 没建账号时，经过反向代理来的请求一律拒绝。
5. **清理数据噪音**：
   - 自动识别下载站插入的推广页（13 页），阅读时跳过，跨页配对也随之修正；
   - 读者只看到有用的译注；
   - 隐藏只有编号的块和页面类型标签；
   - 每本自动找到真正的封面。
6. **部署**：`publish` 导出、`setup.sh` 一条命令初始化服务器、`sync.sh` 增量同步；修好了 macOS rsync 参数、远端文件权限、反向代理识别这几个问题。
7. **新视觉**：图标 A（红底、斜放的纸页、蓝色镜片）+ Dela Gothic 字标「MagLens」配片假名贴纸「マグレンズ」；首页改成街头风格：「继续阅读」黄卡片、按系列分区、封面加黑框和硬投影。
8. **上线和网页端账号管理（2026-11-12）**：部署到 maglens.net；管理员在网页上新建、删除账号，重置密码，改角色。重置密码会让对方的旧会话失效（会话 token 里带了密码指纹，所以这次升级后所有人都要重新登录一次）；不能删除自己或取消自己的管理员身份；每次修改前都会重新读取 `auth.json`，所以和命令行同时用也不会互相覆盖。

9. **按账号限制可看的杂志 + 项目规范（2026-11-12）**：
   - 账号可以带一个 `mags` 列表，只能看列出的那几期；其他期在书架上看不到，直接访问也返回 404。管理员在网页「账号」的「可看」里设置，也可以用命令行 `python -m maglens.users scope 名字 杂志id`（`list` 会列出杂志 id）。用于小红书公开的试读账号，只开放 2026 年 11 月号，朋友的账号不受影响。
   - `auth.json` 被其他进程改动后（比如在服务器上用命令行改账号），服务器会自动重新读取，不需要重启。
   - **出错时保守处理**：`auth.json` 格式写坏了、读不了或者暂时不存在时，服务器继续用内存里已经加载的账号，不会关掉登录，也不会让整个网站报错；网页上的账号管理会返回 503，拒绝在读不出来的文件上覆盖保存。所以想一次性作废所有账号，不能靠删除 `auth.json`，要用 `maglens.users remove` 逐个删除，或者删除后重启服务。
   - 用命令行 `users add` 重新添加已有账号（等于改密码）时，会保留原来的期数限制；`scope` 只接受已经翻完的杂志 id，不能用在管理员身上。
   - 工作流程（用户 2026-11-12 定的）：每个改动先在功能分支上提交，经过 code review 后合并进 main，然后接着做下一项，见 CLAUDE.md。
   - 新增 `CLAUDE.md`（`AGENTS.md` 是指向它的链接）和开发计划 `docs/ROADMAP.md`（后来改成只放本机）。
10. **反馈接口（后端，2026-11-12）**：为 ROADMAP P0「站内反馈按钮」先做后端，前端按钮另一个会话做。
   - `POST /api/feedback {mag_id, page, text}`：任何登录用户都能发；只能针对自己看得到的那一期（试读账号对隐藏的期数发反馈返回 404，和直接访问一样）；`page` 从 0 开始，必须在页数范围内；文字去掉首尾空白后 1–1000 字。同一账号在同一 IP 每小时最多 20 条，超过返回 429（按 IP 分开算，因为试读账号是公开共用的，一个人刷满不能挡住其他人）。
   - 存在服务器的 `data/feedback.jsonl`，每行一条（UTC 时间、用户名、杂志 id 和标题、页码、内容），写入加了锁；上一条如果写到一半中断，下一条会另起一行，不会跟着坏掉。和 `auth.json` 一样只在服务器上，`sync.sh` 同步数据时排除了它；查看方法见 DEPLOY.md。
   - `GET /api/feedback?limit=`：只有管理员能看，最新的在前，默认 200 条，最多 1000。读者看不到任何人的反馈，包括自己的。

11. **手机阅读改版 + 反馈按钮（2026-11-12）**：
   - 竖屏手机：杂志页铺满屏幕，译文放进底部抽屉，有三档高度（只露一条页面标题 / 半屏 / 几乎全屏）。拖动把手调整高度，点一下把手在三档之间切换；用户上次停在哪一档会被记住，翻页时保持不变。点页面上的文字，抽屉升到半屏，滚到对应段落并高亮。抽屉顶部那一条显示这一页的标题和页码，两边有翻页按钮（方向跟随装订方向）。
   - 「点读」模式（顶栏按钮，只在手机上出现）：点文字直接在旁边弹出气泡显示译文，点气泡切换原文，点页面空白处关闭。这样只看杂志、偶尔查一句的时候不用拉抽屉。
   - 选这个方案的原因（用户定的）：杂志本身的视觉才是重点，读者只是需要语言上的帮助；「文字优先」的排法本末倒置，所以不做。
   - 手机上固定显示整页（不提供适应宽度、缩放按钮，需要放大可以双指缩放），隐藏缩略图。用 `100dvh` 和 safe-area 处理 iOS 地址栏和底部横条。横屏手机仍然左右分栏，但收起缩略图和缩放控件。
   - 译文末尾加了「这一页的翻译有问题？告诉我」，读者提交后管理员在顶栏「反馈」里查看；反馈内容一律当纯文本显示（公开试读账号可能提交任何内容）。

12. **公开仓库整理（2026-11-12）**：README 改成英文为主（`README.md`），另有中文版 `README.zh-CN.md`，互相链接。开发计划不再放在 GitHub：之前开的 10 个规划 issue 已删除，`docs/ROADMAP.md` 移出仓库、只留在本机。原因：仓库是公开的，issue 区留给外部的 bug 报告和建议（加了中英双语的 issue 模板，不允许空白 issue），读者的意见走网站里的反馈按钮。

13. **安全响应头 + 服务器备份（2026-11-12）**：
   - 安全响应头由应用自己发送，不只靠 Caddy，这样本机运行和测试里看到的和线上完全一样：CSP（脚本只能来自本站，不允许内联脚本和 `onclick=` 这类内联事件，也不允许被别的网站用 iframe 嵌入）、nosniff、Permissions-Policy；HTTPS 访问时再加 HSTS（一年）。登录页的脚本因此拆成了 `web/login.js`。有测试会检查 `web/` 里不能出现内联脚本，以后加功能时也要遵守。
   - `deploy/backup.sh admin@<服务器IP>`：把服务器上独有的文件（`auth.json`、反馈、访问日志）打包备份到本机 `~/.maglens/server-backup/`，只保留最近 30 份，目录权限 700。**不要放进 iCloud 或网盘**，里面有密码哈希和会话签名密钥。

14. **读者限速 + 访问日志（2026-11-12）**（新文件 `maglens/guard.py`）：
   - 只限读者（管理员和本机模式不受限）。按「账号 + IP」计：大图和译文每分钟 120 次、每小时 600 次，缩略图每 10 分钟 400 次；另外整个账号（不分 IP）大图、译文各每小时 3000 次，防止公开试读账号被很多 IP 一起刷。IPv6 按 /64 网段算一个来源。超过返回 429「看得太快了，休息一下再继续」，带 Retry-After。认真读一整期大约 200–400 次请求，所以正常阅读碰不到；整本扒下来一个 IP 每小时最多三期左右，而且都有记录。
   - 访问日志 `access.jsonl`（只在服务器上，`sync.sh` 不会覆盖）：读者每打开一页译文记一行，被限速也记（同一来源每 10 秒最多一行）；超过 20MB 轮换成 `.1`。管理员接口 `GET /api/access/summary?hours=24` 按账号汇总浏览数、页数、IP 数、最后访问时间、被限速次数。
   - 反馈和访问日志共用 `guard.JsonlFile`（加锁追加、修复截断的行、轮换）。

15. **手机顶栏 + 页面水印（2026-11-12）**：
   - 手机上杂志切换只显示期号（如「11月号」），完整名称在提示和读屏标签里；短名重复时自动补年份或系列名。只能看一期的账号（公开试读）不显示下拉框，只显示期号文字。
   - 登录后每页图片上平铺极淡的斜向「用户名 · 网址」水印（不透明度 0.07，白字细黑边，浅色深色页面都适用），只在阅读页，书架封面和本机单用户模式没有。**只是防随手截图外传**：长按存图或直接打开图片地址拿到的仍是原图；要更强得在服务器端按账号把水印印进图片，需要另外决定。

## 已知问题

- 限速计数在内存里，服务重启就清零（登录、反馈的限速也一样）。公开试读账号的「整账号每小时 3000 次」是所有人共用的：有人故意用很多 IP 刷满，其他试读的人会被拦最多一小时。觉得太紧可以调 `guard.RULES`。
- 前端还没处理 429：图片被限速时只显示一张坏图、没有提示，而且这个地址不会再被预加载。正常阅读碰不到，以后可以加一句提示。
- 反馈的频率限制记在内存里，重启服务后清零（量很小，够用）。
- 4 月号第 145 页没有译文（内容过滤）。可以换 Sonnet 单独重试，也可以不管。
- Haiku 的小毛病：个别术语音译（如 Nomex 写成「诺梅克斯」），页面类型标签常标错（已对读者隐藏）。之前的译注噪音已经在显示层过滤，提示词也改了，但已经翻好的数据没有重翻。
- 「继续阅读」只记在当前浏览器里，换设备不同步。
- `deploy/setup.sh` 只支持 Ubuntu（`apt-get`）。线上那台是 Alibaba Cloud Linux 4，是照着脚本手动部署的，`sync.sh` 可以直接用。
- `maglens.publish` 不能两个进程同时运行：临时文件名固定是 `xxx.tmp`，会互相覆盖并报错。导出时别同时跑两个（比如两个 Claude session 一个在导出、一个在 `sync.sh`）。
- 部署时修掉的（2026-11-12）：上传代码时会把 `docs/` 里的样张 PDF 一起传上去，现在 `setup.sh`、`sync.sh` 都排除了 `*.pdf`；加账号的命令先 `cd` 再 `sudo -u maglens`，因为 `/opt/maglens` 只有 maglens 用户能进入而失败，改成 `sudo -u maglens env -C /opt/maglens/app …`。
